# archive/validation_audits/

Scientific validation Stages 1-6 produced JSON/CSV/PNG audits under `output/`
(e.g. `stage1_data_validation.json`, `stage2a_biological_validation.json`).

Those files were **not moved** (paper `output/` artifacts and audit dumps remain in place
for traceability). They are **not** regenerated by `run_pipeline.py`.

Historical phase run logs live in `archive/logs/`.

For manuscript reproduction, rely on Phases 01-10 outputs documented in `OUTPUTS.md`.
